
# 🛡️ SafeCircle – Women's Safety Website

## 📌 About the Project
SafeCircle is a women’s safety website designed to help women stay aware, informed, and safe. It provides useful safety information and features to support users in emergency and everyday situations.

## 🎯 Objectives
- Promote women's safety and awareness.
- Provide practical safety tips.
- Allow users to register and log in.
- Provide a personal user dashboard.
- Offer a safety check-in feature.

## ✨ Features
- Home Page
- User Registration
- User Login
- User Dashboard
- Safety Tips and Awareness
- Safety Check-in Button
- Responsive Website Design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Python (Flask)
- SQLite Database
- Git and GitHub
